# Hardware

The initial target is the unmodified **Waveshare ESP32-C6 Touch AMOLED 1.64** module. This baseline contains no custom PCB and makes no fabrication-readiness claim.

Issue #8 tracks an optional low-voltage carrier/interface board with editable KiCad sources, schematic-backed exact MPNs, manufacturer datasheets, antenna keepout, ERC/DRC evidence, BOM, fabrication outputs, assembly notes, and mechanical references. No mains, medical, life-safety, or certified-RF-module redesign is in scope.
